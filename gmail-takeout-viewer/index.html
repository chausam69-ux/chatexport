Read your Google Takeout
mail export.

Google Takeout exports Gmail as one large .mbox file with no viewer. This page opens it directly in your browser: browse, search and read every message, with attachments, without re-importing into Gmail or uploading to a third party.

Open the Takeout viewer →

Go to takeout.google.com → deselect all → select Mail → export. Choose a larger archive size (e.g. 50 GB) so the mbox isn't split.

Unzip the archive and find Mail/All mail Including Spam and Trash.mbox.

Drop that file on the viewer. Search, read, save attachments or .eml files.

FAQ

Why is my Takeout mbox so large?

It includes every message with attachments, including Spam and Trash. Labels are stored as headers (X-Gmail-Labels).

Can I put the mail back into Gmail?

Not from here — that needs an IMAP upload tool and Gmail throttles it heavily. This viewer is for reading and searching the archive.

Does it read Gmail labels?

Labels appear in the message headers as X-Gmail-Labels; label filtering is planned.
