FAQ

How do I open an MBOX file on Windows or Mac?

Drop it on this page. No Thunderbird, no Outlook, no converter. Works in Chrome, Edge, Firefox and Safari.

Is my email uploaded anywhere?

No. This is a static page with no server. Open the browser network tab: after page load, zero requests are made.

Can it handle large Gmail Takeout files?

Yes. The file is scanned in chunks and only message boundaries and headers are kept in memory. Bodies are parsed when you click a message.

Can I convert MBOX to PDF?

Open a message and click Print → Save as PDF. Bulk export is on the roadmap.
