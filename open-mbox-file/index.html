Open an .mbox file
without installing anything.

An .mbox file is a plain-text mailbox: every email stacked in one file. Windows and macOS can't open it natively. Instead of installing Thunderbird or uploading your mail to a converter site, drop the file here — it's indexed in your browser and never uploaded.

Open the MBOX viewer →

Locate the .mbox (Google Takeout puts it under Mail/, Thunderbird under its profile folder, Apple Mail exports as a folder containing mbox).

Drop it on the viewer. Multi-GB files are fine — only message boundaries and headers are read up front.

Search by sender, subject or date. Click a message to read it, save attachments, download as .eml, or print to PDF.

FAQ

Can I open a 10 GB Gmail Takeout mbox?

Yes. The file is scanned in 8 MB chunks; memory use stays small regardless of size.

Is anything uploaded?

No. This is a static page with no backend. Turn off your connection after it loads and it still works.

What about Apple Mail .mbox folders?

Apple Mail exports a folder named *.mbox containing an mbox file inside — open that inner file.
